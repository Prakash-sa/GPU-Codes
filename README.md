GPU stacks) and a GPU hardware reference sheet.

**Read online:** <https://prakash-sa.github.io/GPU-Codes/>

## Building locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve          # http://127.0.0.1:8000
```

## Running the LeetGPU solutions

```bash
pip install torch triton
python docs/leetgpu/05_softmax.py                     # tests + benchmark on a CUDA GPU
PROFILE=1 python docs/leetgpu/05_softmax.py           # + torch.profiler table and trace
TRITON_INTERPRET=1 python docs/leetgpu/05_softmax.py  # no GPU: kernels run on the CPU
```

## Regenerating the figures

The PNGs and animated GIFs in `docs/assets/img/` are generated by
`scripts/make_figures.py`, `scripts/make_leetgpu_figures.py` and
`scripts/make_comm_figures.py` (matplotlib). Flow
diagrams are inline Mermaid blocks.

```bash
pip install -r requirements-figures.txt
python scripts/make_figures.py
python scripts/make_leetgpu_figures.py
python scripts/make_comm_figures.py
```

## Publishing to GitHub Pages

`.github/workflows/pages.yml` builds the site with `mkdocs build --strict` and
deploys it on every push to `main`. You only need to turn it on once: in the
repository on GitHub, go to **Settings → Pages → Build and deployment → Source**
and choose **GitHub Actions**.
